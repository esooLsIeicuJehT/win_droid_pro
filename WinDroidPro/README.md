# WinDroid Pro Android project

See the [repository README](../README.md) for implemented features and limits, [build instructions](BUILD_INSTRUCTIONS.md), [user guide](USER_GUIDE.md), and [phone validation checklist](TEST_PLAN.md).

The `:runtime` Android library prepares source and assets from the pinned `vendor/winlator` submodule. The `:app` module retains WinDroid Pro's Compose UI, database and application ID.
