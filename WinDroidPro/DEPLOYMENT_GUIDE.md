# Distribution

Build and verify using [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md), sign with your own private key, and complete [phone validation](TEST_PLAN.md) before describing a release as device-tested. Release APKs are unsigned by default. Preserve source, upstream licenses and [notices](../THIRD_PARTY_NOTICES.md) with distributions. This API-28 runtime is intended for sideloading.
